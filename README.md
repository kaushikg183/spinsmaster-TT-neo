# SpinMaster TT // Neon Court Package

## What's Inside This ZIP
1. `index.html` — Complete single-file **Cyberpunk / Blade Runner Neon Court** SpinMaster TT app (1v1 & 2v2, official serve rotation + Deuce 1-serve tracker, Web Speech API live announcer, 40-step Undo, and the **Invite Modal** with both the direct 1-tap APK link and Web PWA link).
2. `manifest.json`, `sw.js`, `icon.svg` — Full PWA support so iPhone & Android users opening `https://kaushikg183.github.io/spinmaster-tt/` can tap **Add to Home Screen** and launch it full-screen like a native app.
3. `.github/workflows/release-apk.yml` — Drop-in GitHub Actions workflow that automatically renames the built APK to `SpinMaster-TT.apk` and publishes it to a public GitHub Release so this 1-tap URL always works without login:
   `https://github.com/kaushikg183/spinmaster-tt/releases/latest/download/SpinMaster-TT.apk`
